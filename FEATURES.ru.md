# Возможности

**Сшивка, которая прощает реальную съёмку**
- Любой порядок кадров, любая камера, любая смесь объективов. Фишай распознаётся по названию объектива.
- Каскад, который тратит усилия только там, где нужно: быстрый проход на ~1 Мп, затем повышенное разрешение только для кадров, что не села, и, наконец, датчики гравитации и компаса.
- Датчики — подсказка, а не истина. Гравитация (надёжна) и азимут компаса (часто врёт — при съёмке iPhone с рук вплоть до 180°) учитываются раздельно: соседи ищутся по высоте над горизонтом, а связь против компаса принимается, если две опоры указывают одно и то же место. Горизонт выравнивается по гравитации.
- Фокусное расстояние из EXIF уточняется прямо в расчёте и используется для всех кадров: у сверхширика оно нередко «гуляет» на несколько процентов — частая причина панорам, которые не замыкаются.
- Повторяемость: одни и те же фото всегда дают одну и ту же панораму.

**Настоящий HDR, а не тонмаппинг**
- Брекеты можно снимать *как угодно*: с рук, вперемешку, без заданной схемы. Кадры одной позиции автоматически собираются в стопки (по времени съёмки, по изображению и по датчикам).
- Линейный конвейер в half float. RAW читается линейно; HEIC с gain map разворачивается в HDR. Экспозиция каждого кадра берётся из EXIF и уточняется по перекрытиям.
- Смешивание в три полосы: тон неба и засветка объектива переходят плавно, детали остаются резкими.
- **Удаление призраков:** там, где кадры не согласны (сдвинувшиеся люди и машины, брекет с рук, сдвинутый на пару пикселей), точка берётся из согласных кадров — только реальные пиксели, без полупрозрачных «призраков».
- **Честные данные:** каждый пиксель знает, пересвечен ли он во всех экспозициях; **отчёт о качестве HDR** даёт вывод и рецепт («солнце пересвечено — доснимите с ND на 12–16 стопов») и бейдж источника (RAW / HEIC gain map / sRGB). Неснятые места заливаются плавно и помечаются как синтетика.
- **ND-фильтры и солнечный брекет:** укажите, какие кадры сняты через ND (стопы, ND1000, d3.0); тёмный кадр солнца используется только там, где всё остальное пересвечено.

**Режимы сшивки**
- **Быстро** — проверить покрытие.
- **Максимум** — проверить все пары кадров при полной сшивке (по умолчанию).

**Посмотреть, проверить, поправить**
- Плоский и сферический просмотр с зумом и сдвигом. Двойной клик в любом месте выбирает кадр, который закрывает эту точку.
- Список кадров с группировкой «Все / Позиции / Экспозиции», значками EV и метаданными.
- Любой кадр можно поправить вручную: полный поворот / наклон / крен (±180°), быстрые повороты на 90° и 180°, масштаб — или просто **перетащить его прямо на панораме**. Кадр можно убрать из панорамы или удалить и пересшить.
- Экспозиции одной позиции связаны замочком (выделяются и двигаются вместе) — откройте замок, чтобы подвинуть одну. Если сшивка разделила одну позицию на две, **перетащите кадр на другую позицию** — они объединятся.
- **Отмена и повтор** (⌘Z / ⇧⌘Z) для удаления, перемещения и любых ручных правок.
- **Эталонные преобразования просмотра:** Standard (sRGB), **ACES 2.0** SDR и **HDR (EDR)**, ACES 1.3, Khronos PBR Neutral, Raw. Шейдеры ACES генерирует OpenColorIO из официальных конфигов ACES; «Справка → Проверить точность просмотра» сравнивает результат GPU с OpenColorIO.
- Переключатель **«Прокси»** для плавного перетаскивания; превью 8K в покое.
- Коррекция только для просмотра: экспозиция, контраст, светлые, тени, гамма, температура, оттенок, насыщенность, гистограмма, пересветы/провалы и ложные цвета (стопы). На экспорт она не влияет. Можно загрузить свой **LUT .cube** для просмотра.
- **Режим «Рендер»:** серый шар 18%, хромированный шар и пол, освещённые только вашей панорамой (трассировка путей), — проверьте свет и тени от солнца, не выходя из приложения.
- **Сцена:** единый баланс белого с пипеткой, север в центр по компасу iPhone, горизонт по двум точкам.
- **Ретушь:** маски «Исключить / Принудительно» по позициям, заполнение надира, которое собирает круг штатива из кусочков настоящей земли вокруг (помечается как синтетика), швы graph-cut по желанию и проверка сшивки — ошибка шва каждого кадра в пикселях 8K-панорамы.

**Экспорт**
- Форматы: **OpenEXR** (half или 32-битный float, ZIP / PIZ / ZIPS, `envmap = latlong`, chromaticities, метаданные съёмки, по желанию каналы `mask.saturated` / `mask.synthetic`), **Radiance HDR**, **PNG 16 бит**.
- Размеры от 2K до 16K (всегда 2:1).
- Цветовые пространства: Linear Rec.709, ACEScg, Linear Display P3, sRGB, Display P3.

**Проекты**
- Каждая сшивка сохраняется автоматически вместе с кадрами и ручными правками.
- Проекты открываются примерно за секунду: проявленные кадры кэшируются внутри проекта.
- Можно хранить в проекте *копии* фото (откроется всегда) или только *ссылки* на оригиналы (почти не занимает места).

**Ещё**
- Интерфейс на английском и русском (Настройки → Язык), акцентный цвет (Настройки → Оформление).
- Работает полностью офлайн: ни аккаунтов, ни аналитики, ни сетевого кода.
